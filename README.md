# Draft Center

A live TV companion for Sleeper fantasy-football drafts. Draft Center reads Sleeper's public draft data and renders a broadcast-style draft board with on-the-clock graphics, keeper-aware draft order, analysis alerts, pressure mode, manager aliases, absent/auto-draft flags, rotating insight panels, and optional crowd/whistle effects.

## Hosting

This repository is designed to run as a static GitHub Pages site. Once Pages is enabled for the `main` branch, the site URL will be:

`https://wlatic.github.io/draft-center/`

Use the settings panel in the app to paste a Sleeper draft URL/ID and configure manager broadcast names, absent status, auto-draft status, roast level, and audio.

## Data

Live draft data comes from Sleeper's public API. Browser settings are stored locally on the device running the display.
